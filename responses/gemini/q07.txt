To answer each part, we analyze the behavior of multiple hypothesis testing under the null hypothesis (where no metric has a true effect).Step-by-Step Calculations(a) Probability that at least one metric is declared significantThe probability that a single metric is not declared significant (a true negative) is:$$1 - \alpha = 1 - 0.05 = 0.95$$Since the $20$ metric tests are independent, the probability that all $20$ metrics are not declared significant is:$$(0.95)^{20} \approx 0.358486$$The probability of getting at least one false positive (the Family-Wise Error Rate) is the complement of all metrics being non-significant:$$P(\text{at least 1 false positive}) = 1 - (0.95)^{20} \approx 1 - 0.358486 = 0.641514$$Converting to a percentage, this is approximately $64.15\%$.(b) Expected number of false positivesLet $X$ be the number of false positives out of $N = 20$ independent tests. Since no metric changed, each test is a Bernoulli trial with success probability $p = \alpha = 0.05$.The expected value of a binomial distribution is given by:$$E[X] = N \times \alpha = 20 \times 0.05 = 1$$The expected number of false positives is $1$.(c) Significance threshold with a Bonferroni correctionThe Bonferroni correction controls the overall Family-Wise Error Rate at target level $\alpha = 0.05$ by dividing the significance threshold by the total number of tests $N$:$$\alpha_{\text{Bonferroni}} = \frac{\alpha}{N} = \frac{0.05}{20} = 0.0025$$The adjusted significance threshold for each individual test is $\alpha = 0.0025$ (or $p < 0.0025$).Final Answers(a) $1 - (0.95)^{20} \approx \mathbf{64.15\%}$ (or $0.6415$)(b) $20 \times 0.05 = \mathbf{1}$(c) $0.05 / 20 = \mathbf{0.0025}$
