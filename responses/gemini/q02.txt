To calculate the 95% Wald confidence interval for the population proportion, follow these steps:1. Compute the Sample Proportion ($\hat{p}$)$$\hat{p} = \frac{x}{n} = \frac{120}{400} = 0.30$$2. Identify the Critical Value ($z^*$)For a 95% confidence level, the standard normal critical value is $z^* = 1.96$.3. Calculate the Standard Error ($\text{SE}$)$$\text{SE} = \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} = \sqrt{\frac{0.30 \times (1 - 0.30)}{400}} = \sqrt{\frac{0.21}{400}} = \sqrt{0.000525} \approx 0.02291$$4. Determine the Margin of Error ($\text{ME}$)$$\text{ME} = z^* \times \text{SE} = 1.96 \times 0.02291288 \approx 0.04491$$5. Construct the Confidence Interval$$\text{CI} = \hat{p} \pm \text{ME} = 0.30 \pm 0.04491$$Lower Bound: $0.30 - 0.04491 = 0.2551$ (or $25.51\%$)Upper Bound: $0.30 + 0.04491 = 0.3449$ (or $34.49\%$)The 95% Wald confidence interval for the population proportion is [0.2551, 0.3449] (or 25.51% to 34.49%).
